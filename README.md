# Yalla! 🚀

Application familiale pour apprendre **l'anglais**, **l'arabe littéraire** (avec l'alphabet) et
**la darija algérienne** — comme Duolingo, avec le vocal complet : l'app prononce, tu répètes au
micro, elle corrige.

**➡️ L'app : https://ecotrans69.github.io/yalla/**

## Installer sur téléphone / tablette

### iPhone / iPad (Safari)
1. Ouvre le lien ci-dessus dans **Safari**
2. Bouton **Partager** (carré avec flèche) → **« Sur l'écran d'accueil »**
3. L'icône verte Yalla! apparaît comme une vraie app

### Android (Chrome)
1. Ouvre le lien dans **Chrome**
2. Menu **⋮** → **« Ajouter à l'écran d'accueil »** (ou le bouton « Installer » proposé par l'app)

Une fois installée, l'app marche **même sans internet** (seul le micro a besoin du réseau sur
certains téléphones).

## Ce qu'il y a dedans

- 🇬🇧 **Anglais** : 8 unités, 32 leçons, 264 mots et phrases
- 📖 **Arabe littéraire** : l'alphabet complet (28 lettres, toutes leurs formes) + 6 unités de vocabulaire vocalisé avec phonétique
- 🇩🇿 **Darija algérienne** : 6 unités, 170 expressions du quotidien en phonétique
- 🔊 Prononciation par la voix du téléphone (bouton 🐢 pour ralentir)
- 🎤 Exercices « écoute et répète » corrigés au micro avec score
- ❤️ Cœurs, ⚡ XP, 🔥 séries de jours, 👑 couronnes, badges, objectif quotidien
- 📝 Révision intelligente : les mots ratés reviennent plus souvent
- 👨‍👩‍👧‍👦 Plusieurs profils par appareil + mode enfant + classement famille
- 🌙 Mode sombre, téléphone et tablette

Toutes les données restent sur l'appareil — aucun compte, aucun serveur.

## Développement

```bash
npm install
npm run dev      # serveur de développement
npm test         # 91 tests (moteur, contenu, UI)
npm run build    # build de production + PWA
```

Déploiement automatique sur GitHub Pages à chaque push sur `main`.
