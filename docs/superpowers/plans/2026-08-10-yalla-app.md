# Yalla! Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA familiale type Duolingo (anglais, arabe littéraire avec alphabet, darija algérienne) avec vocal complet (TTS + répétition micro corrigée), gamification, multi-profils, offline, déployée sur GitHub Pages.

**Architecture:** SPA React + TypeScript (Vite) sans backend. Moteur d'exercices pur TS (`engine/`) testé unitairement, contenu 100 % data (`content/*.json`), stockage local (`store/`), wrappers voix (`speech/`), UI mobile-first (`ui/`). Service worker précache tout (vite-plugin-pwa).

**Tech Stack:** React 18.3, TypeScript 5.x, Vite 6, vite-plugin-pwa, Vitest + @testing-library/react + jsdom. Zéro dépendance runtime hors react/react-dom.

## Global Constraints

- Toute l'UI en **français simple** (public familial, enfants inclus).
- **Aucun appel réseau à l'exécution** (hors chargement initial) : contenu bundlé, voix = APIs navigateur.
- Projet dans `~/Projects/yalla` — JAMAIS de fichier sur `~/Desktop/` (règle Sofian). JAMAIS le VPS.
- Base path Vite : `/yalla/` (GitHub Pages). Routing par **hash** (`#/...`).
- Texte arabe affiché avec `dir="rtl"` et `lang="ar"`, police système, taille ≥ 1.4em.
- Moteur déterministe : `rng: () => number` et `now: () => number` injectés partout (testabilité).
- Heure de FRANCE (`Europe/Paris`) pour streak/objectif quotidien.
- Design : primaire vert `#58CC02`, erreur `#ff4b4b`, or `#ffc800`, fond clair `#fff` / sombre `#131f24`, cartes arrondies 16px, gros boutons (min-height 48px), mode sombre via `prefers-color-scheme` + toggle.
- Commits fréquents, messages en français, `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
